# BiblioFlow: documentazione di progetto (consegna ISTA)

Documenti di progetto del sistema BiblioFlow, consegnati per l'insegnamento di
**Ingegneria del Software: Tecniche Avanzate (ISTA)**, Laurea Magistrale in
Informatica, Università degli Studi di Salerno, **A.A. 2025-2026**.

**Autori:** Mario Celzo, Renato Mancino, Alfonso Maria Ferrara

## Documenti

I file sono in ordine di lettura; il prefisso numerico indica la sequenza.

1. **Report di Progetto** (`1 - Report_Progetto.pdf`): descrizione del sistema di
   partenza, con contesto, package, flussi di funzionamento e diagrammi.
2. **Change Requests** (`2 - Change_Requests.pdf`): le richieste di modifica
   che guidano l'intervento evolutivo.
3. **Impact Analysis** (`3 - Impact_Analysis.pdf`): analisi dell'impatto delle
   modifiche sul codice, con call graph, matrici di raggiungibilità e metriche
   di precision e recall.
4. **Master Test Plan** (`4 - Master_Test_Plan.pdf`): strategia di test, livelli
   di test e criteri di accettazione.
5. **Pre-Modification Test Document** (`5 - Pre_Modification_Test_Document.pdf`):
   casi di test specificati prima della modifica, con esito sulla baseline.
6. **Pre-Modification Test Incident Report** (`6 - Pre_Modification_Test_Incident_Report.pdf`):
   incidenti emersi durante l'esecuzione della suite sulla baseline.
7. **Post-Modification Test Execution** (`7 - Post_Modification_Test_Execution.pdf`):
   casi di test aggiunti, modificati, eliminati e invariati, esecuzione sulle
   parti modificate, regressione, copertura e test end-to-end.
8. **Report Finale** (`8 - Report_Finale.pdf`): sintesi del percorso evolutivo
   e dei relativi esiti.
